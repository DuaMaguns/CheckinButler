==========================================================
 🐍 使用前必读 · 环境安装说明
==========================================================

这个签到程序是用 Python 写的，运行它需要先安装 Python 环境。

👉 正确的启动顺序：
   1. 先读完本文件
   2. 确认 Python 已安装（往下看怎么装）
   3. 再双击 cli.bat 启动程序


----------------------------------------------------------
 一、怎么判断我有没有 Python 环境？
----------------------------------------------------------

最简单的办法：直接双击 cli.bat。

 ✅ 如果正常弹出控制台菜单/向导 → 环境已就绪，不用再折腾
 ❌ 如果提示 "[ERROR] Python not found" → 按下面第二节安装


----------------------------------------------------------
 二、安装 Python（免费，5 分钟搞定）
----------------------------------------------------------

 1. 打开官网下载页：https://www.python.org/downloads/
    （cli.bat 检测不到环境时会自动帮你打开这个页面）

 2. 点击黄色大按钮下载最新版（3.8 以上都可以）

 3. 运行安装程序，⚠️ 最关键的一步：
    勾选底部的 「Add python.exe to PATH」
    再点 Install Now
    （不勾这个，装完也找不到，等于白装！）

 4. 装完后重新双击 cli.bat 即可


----------------------------------------------------------
 三、常见问题
----------------------------------------------------------

 Q：装完还是提示找不到 Python？
 A：安装时忘了勾 "Add python.exe to PATH"。
    重新运行安装程序选 Modify，勾上 PATH 选项；
    或者打开 cli.bat，把里面 PYEXE 那行改成
    你电脑上 python.exe 的完整路径。

 Q：微软商店那个 Python 能用吗？
 A：能，但更推荐官网版。若用商店版，装完在
    「管理应用执行别名」里确认 python.exe 别名已开启。

 Q：为什么要 Python？能不能打包成免安装的 exe？
 A：当前版本保持零依赖纯标准库，体积小、可审计、
    免杀毒软件误报。Python 安装一次就永久可用。
