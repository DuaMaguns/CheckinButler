# 04 · 通知配置

支持两个推送渠道，二选一或都配（优先企业微信）。

## 主路线：CLI 交互式绑定（推荐）

打开 `cli.bat` → 菜单按 `5` → 选企业微信 → 粘贴 Webhook 地址回车。脚本会：

1. 自动提取 key（粘整个 URL 或只粘 key 段都行）
2. **当场试发一条验证消息**——群里弹出来才算配置成功
3. 成功后自动写入 `config\checkin_env.bat`

失败会给出明确原因（key 不完整 / 93000 无效 / 网络不通）。

## 方式一：企业微信消息推送(群机器人)（手动）

1. 打开要收日报的微信群 → 右键 → **添加消息推送(群机器人)** → 新建一个机器人（如「签到助手」）
   （新版企业微信叫「消息推送」，旧版叫「群机器人」，是同一个东西）
2. 创建完会得到一个 Webhook 地址：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
3. 复制 `key=` 后面那串（**只要 key，不要整个 URL**）
4. 打开 `config\checkin_env.bat`，填入：
   ```bat
   set "QYWX_TOKEN=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
   ```

验证：跑一次 `run_checkin.bat --force`，群里应收到日报，日志里出现
`WeCom push: OK {'errcode': 0, 'errmsg': 'ok'}`。

常见回执错误：

| errcode | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | — |
| 93000 | webhook key 无效 | 检查是否复制完整、机器人是否被删 |
| 45009 | 频率超限 | 正常不会触发（有当日闸门） |

## 方式二：PushPlus（推送到微信服务号）

1. 打开 https://www.pushplus.plus/ ，微信扫码登录
2. 首页复制你的 **token**
3. 填入 `config\checkin_env.bat`：
   ```bat
   set "PLUSPLUS_TOKEN=你的token"
   ```

## 日报内容说明

```
📋 每日签到报告 2026-10-10 09:00

Trae（2 个账号）
✅ 账号甲 · 今日已签 · 剩余1,972 · 10-19 15:54到期1,072(8天)
✅ 账号乙 · 今日已签 · 剩余304 · 11-08 21:18到期100(29天)

WorkBuddy（2 个账号）
✅ 昵称一 · 今日已签 · 连签2天 · 剩余1975 · 11-09 13:23到期100(29天)
⏳ 昵称二 · 待重试 · 风控冷却中

Qoder（1 个账号）
✅ 账号1 · 今日已签 · 今日已领取

🟢 全部账号完成 · 成功0 已签5 待重试0 失败0
```

- 每行 = 一个账号：状态图标 + 昵称 + 签到结果 + 连签天数（WorkBuddy）+ 剩余积分 + 最近到期时间与到期积分数
- 状态图标：✅ 已签成功 / ☑️ 当日已签（缓存） / ⏳ 待重试 / ❌ 失败
- 「最近到期」取**仍有余额**的套餐包里最早到期的那个；括号内是剩余天数
- 尾部汇总行：🟢 全部终态 / 🟡 有待重试 / 🔴 有失败

## 推送时机

- 当天第一次运行且**全部账号到达终态** → 推送一次，落完成标记
- 有账号 retry / fail → 每次运行都推（盯补签用），直到全部终态
- 当天已落标记 → 后续运行直接跳过，**不重复推送**
- `--force` 强制执行 → 无论如何都会再推一次
