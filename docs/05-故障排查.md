# 05 · 故障排查

先跑自检，多数问题它会直接指出来：

```
py -3 scripts\doctor.py
```

下面按症状排查。

---

## 1. 某个 WorkBuddy 账号"凭空消失"了

**症状**：昨天还在日报里，今天 `credit` 输出里没有它，也没有任何报错。

**原因 1（最常见）：凭证文件编码不是 UTF-8**。
签到脚本按 UTF-8 读 `auths\*.json`，读到非法字节会**静默跳过**（`continue`），一个字都不提示。

检查与修复：

```
python -c "open(r'scripts\workbuddy-checkin\auths\workbuddy-<uid>.json',encoding='utf-8').read()"
```

报 `invalid start byte` 之类错误就是编码问题。用记事本打开该文件 → 另存为 → 编码选 **UTF-8** 保存。或者干脆重新跑一次 `wb_login.bat`。

**原因 2：文件里 `disabled: true`**。打开文件看一眼，改回 `false`。

**原因 3：`wb_login.bat` 覆盖保存时把别的号删了**。
旧版本脚本有这个 bug（保存新凭证时删除其他账号文件）。检查 `login_quick.py` 保存凭证段落是否为「只覆盖同名 uid、保留其余账号」。本模板已修复，但如果你从旧版迁移凭证，需要核对。

---

## 2. 登录授权到的不是想要的账号

**症状**：`wb_login.bat` 走完流程，保存的凭证昵称是另一个账号。

**原因**：浏览器里已有别的 WorkBuddy 登录会话，授权页直接沿用了它。

**处理**：换**无痕/InPrivate 窗口**重新打开授权链接登录；或先在浏览器里退出当前账号。

---

## 3. 登录后跳转到 127.0.0.1 报"无法访问此网站"

**不是故障**。这是 CLI 授权流程的正常环节，授权信息在跳转前已被服务端记录，脚本轮询拿到后正常落盘。看到这个页面直接关掉即可。

---

## 4. WorkBuddy 签到报 12153 / token 失效

refreshToken 长期没用导致失效（约 30 天不活动）。重新跑 `wb_login.bat` 授权一次即可恢复。日常每天签到的账号不会遇到。

---

## 5. Trae 账号显示 ⏳ 待重试（9074）

Trae 接口风控，触发后账号进入冷却（几小时到一天）。**不要频繁手动重跑**。当天闸门因它不落完成标记，后续每轮自动重试，冷却结束后自然恢复。

---

## 5½. Qoder 账号长期 ⏳ 待下发 / 活动列表为空

大概率是**设备标识（Cosy-MachineToken）过期**。回本机重跑 `qoder_add.bat` 更新 `config.json` 即可。

Qoder 显示 🔑 需重新登录：token 与 refreshToken 均失效，同样重跑 `qoder_add.bat`。

Qoder 每日活动不是零点准时下发，早上的某一轮显示 ⏳ 待下发属正常，后续轮次会自动领。

另：Qoder 脚本请求走系统代理时可能被拦，报网络错误就清掉 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量再试。

---

## 6. 当天重复推送了多条一模一样的日报

检查 `scripts\.checkin_state.json`：

- 存在且 `completed_date` 是今天 → 闸门应该拦截；如果还推了，确认是不是用了 `--force`（force 会强制重推，属预期行为）
- 文件不存在或日期是昨天 → 说明昨天没全部到终态（有 retry/fail），今天每次运行都会推送直到全部终态。把失败账号处理掉即可

删除该状态文件可以强制当天重新走完整流程（不含推送 key 时无副作用）。

---

## 7. 企业微信没收到推送

按顺序查：

1. `config\checkin_env.bat` 里 `QYWX_TOKEN` 是否填了（只要 `key=` 后面那段，不是整个 URL）
2. 日志 `logs\checkin_*.log` 里搜 `Push decision`：
   - `SKIP — 今日已完成且已推送过` → 属正常闸门，用 `--force` 测试
   - `WeCom push: FAIL {'errcode': 93000}` → key 无效，重新生成机器人 webhook
3. 消息推送(群机器人)是否被删除 / webhook 是否被人改过

---

## 8. 计划任务没跑 / 报 0x1

- 「起始于」没填项目根目录（最常见）
- 用的 `python` 没加 PATH，计划任务环境里找不到 → `run_checkin.bat` 会打印 `[ERROR] Python not found`，此时把 bat 里的 `PYEXE` 回退路径改成你机器的 python.exe 绝对路径
- 勾了「不管用户是否登录都要运行」但没存密码 → 任务属性里重新输入

---

## 9. Python 找到了但版本太老

doctor.py 会报 `Python x.y too old`。安装 3.8+，或修改各 bat 里的 `PYEXE` 回退路径指向新装的 python.exe。

---

## 10. 换了电脑 / 换了目录怎么迁移

1. 整个目录拷到新机器（凭证 json 都在里面就是免登录迁移）；或本机双击 `打包.bat` 生成无凭证 zip，新机器解压后重新加号
2. 双击 `cli.bat` —— 没配置会自动走向导，跟着走完即迁移完成（老手可用 `setup.bat` / 手动路线）
3. 菜单按 `1` 跑自检确认全绿
4. 向导第 4 步会在新机器重建计划任务（计划任务不随目录迁移）

不想拷凭证的话：新机器上把各账号重新走一遍 `wb_login.bat` / `trae_add.bat` / `qoder_add.bat` 即可。
