# 02 · 账号管理

> 加号的主入口是 `cli.bat` 菜单 2 / 3 / 4，下文说明的是各平台规则与底层细节。

## WorkBuddy 账号

### 添加账号

`cli.bat` 菜单 2（或双击 `wb_login.bat`），按 [01-快速上手](01-快速上手.md) 第 3 步操作。

**关键注意**：
- 每次登录**务必用无痕窗口**。如果浏览器已有另一个 WorkBuddy 的登录会话，直接登录授权到的还是旧账号，白忙一场
- 登录后跳到 `127.0.0.1` 报错是正常流程，不是故障

### 查看已有账号

```
py -3 scripts\workbuddy-checkin\workbuddy_checkin.py credit
```

输出每个账号的：昵称、剩余积分、最近到期时间、到期积分。

### 停用 / 启用某个账号

编辑 `scripts\workbuddy-checkin\auths\workbuddy-<uid>.json`，把 `disabled` 改成 `true`（停用）或 `false`（启用）。停用的账号不参与签到但仍保留凭证。

### 删除账号

直接删除对应的 `auths\workbuddy-<uid>.json` 文件即可，其他账号不受影响。

### 凭证过期

- accessToken 约 30 天有效期，脚本用 refreshToken 自动续期，通常无感
- 如果 `credit` 命令报 token 失效（如 12153），重新跑一次 `wb_login.bat` 重新授权即可
- 凭证文件**必须保存为 UTF-8 编码**（`wb_login.bat` 已经保证）。如果手工编辑过凭证文件存成了 GBK，签到脚本会**静默跳过**该账号——症状是账号凭空消失，见 [05-故障排查](05-故障排查.md)

## Trae 账号

### 添加 / 刷新账号

1. 打开 Trae 客户端，登录目标账号
2. 双击 `trae_add.bat`
3. 换下一个账号登录客户端，再双击一次

脚本会把账号归档到 `config\trae-accounts\<账号名>.json` 并自动更新 `config\checkin_env.bat` 里的 `TRAE_ACCOUNTS`。

### 手动方式

双击 `get_tokens.bat`，把它输出的 `TRAE_ACCOUNTS`（单行 JSON）粘进 `config\checkin_env.bat`。适合批量迁移或脚本化操作。

### 隐藏特性：自动识别本机 Trae 客户端

如果这台电脑装了 Trae 客户端且已登录，签到脚本会**自动读取客户端的 storage.json 并解密凭证**，即使没配 `TRAE_ACCOUNTS` 也能签。也就是说：

- 只用一个 Trae 账号时，装好客户端就零配置可跑
- 客户端里登录哪个号，脚本就签哪个号（切换登录 = 切换签到账号）
- 显式配置的 `TRAE_ACCOUNTS` 优先级更高，两者可共存

### 删除账号

1. 从 `config\checkin_env.bat` 的 `TRAE_ACCOUNTS` JSON 里删掉对应条目
2. （可选）删除 `config\trae-accounts\` 里的归档文件

### Trae 风控（9074 冷却）

Trae 接口有频率风控，触发后账号进入冷却期（通常几小时到一天），签到脚本会标记 `retry` 并在下一轮自动重试。**不要频繁手动重跑**，等冷却结束即可。当天只要有账号未到终态，"当日完成"闸门就不会落标记，每次运行都会重新尝试。

## Qoder 账号

### 添加 / 刷新凭证

前提：本机装了 Qoder 客户端并登录。双击 `qoder_add.bat` 即可，它会：

1. 从客户端解密出 `Cosy-*` 设备标识 → 写入 `scripts\Qoder-Checkin\config.json`
2. 解密出 accessToken / refreshToken → 按 uid 去重合并进 `accounts.json`

多账号：客户端切换登录 → 再跑一次 `qoder_add.bat`。

### 查看签到结果

直接跑 `py -3 scripts\Qoder-Checkin\02_checkin.py`，输出每个账号的状态。Qoder 的 claim 接口**幂等**，重复跑不会重复发币。

### 状态含义

| 状态 | 含义 | 处理 |
|---|---|---|
| ✅ 签到成功 | 领取成功，到账 N Credits | 无 |
| ☑️ 已领取 | 今天已经领过 | 无 |
| ⏳ 待下发 | 每日活动还没下发（Qoder 不是零点准时发） | 等下一轮自动重试 |
| 🔑 需重新登录 | token 和 refreshToken 都失效 | 重跑 `qoder_add.bat` |
| ❌ 失败 | 网络或接口异常 | 看日志，偶发可忽略 |

### token 自动续期

脚本在 token 到期前 72 小时自动刷新并把新 token 写回 `accounts.json`，长期免维护。只有 refreshToken 也失效时才需要重新提取。

### 设备标识过期

症状：账号长期 `pending` 或活动列表为空。处理：重跑 `qoder_add.bat` 更新 `config.json` 的 device 块。

## 多账号机制说明

- WorkBuddy：`auths\` 目录下每个账号一个 json 文件，数量不限
- Trae：`TRAE_ACCOUNTS` 是 JSON 数组，元素数量不限
- 日报按平台分组列出全部账号
- **当天中途加新号不会被"已完成"挡住**：完成标记里记录了账号集合指纹，集合变了就照常执行，新号能签上

## 当日防重复闸门

`scripts\.checkin_state.json` 记录当天完成状态：

- **全部账号到达终态**（成功 / 已签）→ 落标记，当天再跑直接跳过
- 有任一账号 retry 或失败 → 不落标记，每次运行都重试并推送，方便盯补签
- 强制重跑：`run_checkin.bat --force`（会重新执行并**再次推送**）
