# 03 · 定时任务（Windows 计划任务）

## 主路线：CLI 自动创建

打开 `cli.bat` → 菜单按 `6`：

- **未创建时**：输入每天执行时间（如 `09:00`）回车即创建
- **已创建时**：显示任务详情，可选修改时间 / 删除（删除需确认）
- 任务名固定为 `CheckinTool`，执行的就是根目录 `run_checkin.bat`

## 手动配置（备用）

用 Windows 自带的任务计划程序，每天固定时间自动执行 `run_checkin.bat`。

1. `Win + R` 输入 `taskschd.msc` 回车，打开任务计划程序
2. 右侧点 **创建基本任务**
   - 名称：`每日签到`
   - 触发器：**每天**，时间选每天早上（如 09:00）
   - 操作：**启动程序**
   - 程序或脚本：点浏览，选择项目根目录的 `run_checkin.bat`
     - 例如 `D:\checkin-tool\run_checkin.bat`
   - 起始于（重要，别留空）：填项目根目录，例如 `D:\checkin-tool`
3. 完成创建后，双击这条任务做三个加固设置：
   - **常规**页：勾选「不管用户是否登录都要运行」（可选）；如果机器开着但未登录也想跑，需要勾选并输入密码
   - **触发器**页：可以再加一个触发时间（如 21:00），作为早上失败后的兜底——当天已签完会自动跳过，不会重复推送
   - **设置**页：勾选「如果任务失败，按以下频率重新启动」→ 每 30 分钟，共 3 次

## 为什么"起始于"必须填

`run_checkin.bat` 通过自身路径定位项目根目录（`%~dp0`），一般不依赖工作目录；但计划任务默认工作目录是 `C:\Windows\System32`，个别场景下脚本写日志、找配置会出问题。填上根目录一劳永逸。

## 手动补跑

| 场景 | 命令 |
|---|---|
| 当天已签完，想再跑一遍并重新推送 | `run_checkin.bat --force`（或菜单 7） |
| 换了 / 加了账号后立即生效 | 直接跑 `run_checkin.bat`（账号集合变了会自动执行） |
| 只查积分不签到 | 菜单 8，或 `py -3 scripts\workbuddy-checkin\workbuddy_checkin.py credit` |

## 日志

每天一个日志文件：`logs\checkin_YYYY-MM-DD.log`，记录每次运行的完整过程（签到结果、推送决定、推送回执）。

CLI 菜单按 `9` 可以直接翻看最近 5 天日志的任意尾部行数。

推送决策依据也写在日志里，例如：

```
Push decision: PUSH — 今日首次全部完成，推送汇报
Push decision: SKIP — 今日已完成且已推送过，跳过
```

## 注意事项

- 电脑关机时任务不会执行；开机后可在计划任务里右键 → 运行 补一次
- 笔记本睡眠状态下任务可能延迟；「设置」页可勾选「错过计划开始时间后，尽快启动任务」
- Trae 账号触发 9074 风控冷却时，任务照常跑但该账号标记 retry；闸门不落完成标记，下一轮自动重试
