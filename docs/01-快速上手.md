# 01 · 快速上手

主路线只有一句话：**双击 `cli.bat`，跟着提示走**。本文展开每一步会发生什么，末尾附不用 CLI 的手动路线。

## 前置条件

- Windows 10/11
- Python 3.8 及以上（只装标准库即可，不需要 pip install 任何东西）
  - 检查方法：命令行输入 `py -3 --version` 或 `python --version`
  - 没装就去 https://www.python.org/downloads/ 下载，安装时勾选 **Add Python to PATH**
- 一个企业微信群（收日报用），或 PushPlus 账号

## 主路线：控制台向导

把项目文件夹拷到任意位置（例如 `D:\checkin-tool`），双击：

```
cli.bat
```

首次打开（检测到没有推送配置 / 没有任何账号）会自动进入**五步向导**：

### 【1/5】环境自检

自动检查 Python 版本、配置、凭证、网络连通性。首次使用这里有几个 FAIL/WARN 是正常的，加完账号就会消掉。

### 【2/5】绑定企业微信推送

1. 微信群里：右键 → 添加消息推送(群机器人) → 新建 → 复制 Webhook 地址
   （新版企业微信叫「消息推送」，旧版叫「群机器人」，是同一个东西）
2. 回到控制台，把整个地址粘贴进去回车
3. 脚本自动提取 key 并**当场试发一条验证消息**——看到群里弹出来才算成功
4. 失败会明确告诉你原因（key 不完整 / 网络不通），重粘一次即可

### 【3/5】添加账号

输入要加的平台组合（如 `1,3` = WorkBuddy + Qoder）：

- **WorkBuddy（1）**：脚本打印授权链接 → 浏览器**无痕窗口**打开 → 登录 → 页面跳 127.0.0.1 报错属正常 → 凭证自动落盘
- **Trae（2）**：先在 Trae 客户端登录目标账号，回车即归档
- **Qoder（3）**：先在 Qoder 客户端登录，回车即自动提取设备标识和 token

多账号 = 客户端/浏览器切换登录后再跑一次对应菜单项。

### 【4/5】配置定时任务

输入每天几点执行（如 `09:00`），脚本自动创建 Windows 计划任务。之后可在菜单 6 里改时间 / 删除。

### 【5/5】试跑一次

真实执行三平台签到并推送日报。企业微信里应收到类似：

```
📋 每日签到报告 2026-10-12 09:00

Trae（2 个账号）
✅ 账号甲 · 今日已签 · 剩余1,972 · 10-19 15:54到期1,072(8天)

WorkBuddy（2 个账号）
✅ 昵称一 · 今日已签 · 连签2天 · 剩余1975 · 11-09 13:23到期100(29天)

Qoder（1 个账号）
✅ 账号1 · 今日已签 · 签到成功 +100

🟢 全部账号完成 · 成功1 已签4 待重试0 失败0
```

向导结束后进入日常**数字菜单**：

```
1. 环境自检          2. 添加 WorkBuddy 账号
3. 添加 Trae 账号    4. 添加 Qoder 账号
5. 绑定/修改推送     6. 定时任务（建/改/删）
7. 立即签到一次      8. 账号积分总览
9. 查看日志          0. 退出
```

菜单顶部实时显示：各平台账号数、推送配置状态、定时任务状态。

## 手动路线（不用 CLI）

如果你更喜欢手工控制，各菜单项背后的原入口仍然可用：

| 菜单项 | 手动等价 |
|---|---|
| 加 WorkBuddy 号 | `wb_login.bat` |
| 加 Trae 号 | `trae_add.bat` / `get_tokens.bat` |
| 加 Qoder 号 | `qoder_add.bat` |
| 绑推送 | 编辑 `config\checkin_env.bat` 填 `QYWX_TOKEN` |
| 配定时任务 | `docs\03-定时任务.md` 手动建计划任务 |
| 立即签到 | `run_checkin.bat`（加 `--force` 强制重跑重推） |
| 环境自检 | `py -3 scripts\doctor.py` |

## 分享给别人

双击 `打包.bat` → 生成 `dist\checkin-tool-日期.zip`（凭证已自动排除）→ 发给对方 → 对方解压双击 `cli.bat` 走向导。

## 遇到问题

菜单按 `1` 自检，然后翻 [05-故障排查](05-故障排查.md)。
